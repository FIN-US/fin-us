# backend pip to uv Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert `backend/` from pip/pip-compile requirements files to an independent uv-managed project while keeping runtime behavior unchanged.

**Architecture:** `backend/pyproject.toml` becomes the source of truth for backend dependencies and `backend/uv.lock` becomes the reproducible lockfile. Docker and local commands use `uv sync`/`uv run` against the backend project; the root repo is not converted to a uv workspace.

**Tech Stack:** Python 3.13, uv 0.9.28, FastAPI, uvicorn, pytest, Docker Compose

---

## File Structure

- Create: `backend/pyproject.toml`
  - Responsibility: backend runtime/dev dependency declaration for uv.
- Create: `backend/uv.lock`
  - Responsibility: uv-generated lockfile committed for reproducible installs.
- Delete: `backend/requirements.txt`
  - Responsibility removed: old runtime dependency declaration.
- Delete: `backend/requirements-dev.txt`
  - Responsibility removed: old dev dependency declaration.
- Delete: `backend/requirements.lock`
  - Responsibility removed: old pip-compile lockfile.
- Modify: `backend/Dockerfile`
  - Responsibility: install uv and sync backend runtime dependencies with `uv sync --no-dev --frozen`.
- Modify: `docker-compose.yml`
  - Responsibility: keep backend anonymous venv volume aligned with uv's `.venv` path.
- Modify: `README.md`
  - Responsibility: document uv-based local backend setup and execution.

No application modules or tests should change for this issue.

### Task 3: Convert backend Dockerfile to uv

**Files:**
- Modify: `backend/Dockerfile`

- [ ] **Step 1: Replace backend Dockerfile content**

Replace `backend/Dockerfile` with this content:

```dockerfile
FROM python:3.13-slim

RUN apt-get update && apt-get install -y --no-install-recommends curl ca-certificates gnupg && \
    curl -fsSL https://deb.nodesource.com/setup_24.x | bash - && \
    apt-get install -y --no-install-recommends nodejs && \
    rm -rf /var/lib/apt/lists/*

COPY --from=ghcr.io/astral-sh/uv:0.9.28 /uv /uvx /bin/

WORKDIR /opt/mcp-news
COPY mcp-news/package*.json ./
RUN npm ci --omit=dev
COPY mcp-news ./

WORKDIR /opt/mcp-trading
COPY mcp-trading/package*.json ./
RUN npm ci --omit=dev
COPY mcp-trading ./

WORKDIR /app

COPY backend/pyproject.toml backend/uv.lock ./backend/
RUN uv sync --project ./backend --no-dev --frozen

COPY . .

EXPOSE 8000

CMD ["uv", "run", "--project", "./backend", "--frozen", "uvicorn", "backend.main:app", "--host", "0.0.0.0", "--port", "8000", "--reload"]
```
